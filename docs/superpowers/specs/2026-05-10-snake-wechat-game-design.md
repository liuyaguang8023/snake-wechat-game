# 贪吃蛇微信小游戏 — 设计规格

## 概述

一款微信小游戏贪吃蛇，支持无尽模式和 10 关关卡模式，包含 6 种道具系统。采用 TypeScript + Canvas 原生开发，轻量自建游戏框架。视觉风格为可爱 Emoji 风，纯滑屏操控。

## 技术方案

TypeScript + 微信小游戏原生 Canvas 2D API，自建轻量游戏框架（~300 行核心），不依赖第三方引擎。包体积目标 < 200KB。

## 核心游戏机制

- **网格**：20×30，每格 18px，画布 360×540 逻辑像素
- **蛇**：双向链表存储，O(1) 移动/生长，蛇头带眼睛方向
- **循环**：累积时间控制移动节奏，渲染始终以 RAF 驱动
- **操控**：纯滑屏，忽略 180° 反向输入

### 难度递增（无尽模式）

| 分数 | 移动间隔 |
|-----|---------|
| 0-50 | 200ms |
| 50-100 | 150ms |
| 100-200 | 120ms |
| 200-400 | 90ms |
| 400+ | 70ms |

## 道具系统

六种道具，插件式注册：

| 道具 | 图标 | 持续 | 效果 |
|-----|------|------|------|
| 加速 | ⚡️ | 8s | 间隔 ×0.5，分数 ×2 |
| 减速 | 🐢 | 8s | 间隔 ×2，碰撞放宽 1 格 |
| 无敌 | 🛡️ | 6s | 无视障碍物和自身碰撞 |
| 穿墙 | 👻 | 6s | 穿墙从对面出现 |
| 双倍分数 | 💎 | 10s | 所有得分 ×2，与加速叠加时 ×4 |
| 缩短 | ✂️ | 即时 | 蛇身减 3 节（最少保留 2 节） |

- 每吃 5 食物有 40% 概率刷出道具，场上最多 2 个
- 同类型不可叠加（刷新时间），不同类型可叠加
- 道具持续期间蛇头有图标标记

## 排行榜（预留）

云函数 `cloud/leaderboard/`，云端未配时静默降级，不影响游戏。

## 视觉风格

可爱 Emoji 风，暖色调。蛇身用圆角方块，食物用 🍎，障碍物用 🧱，UI 使用柔和色彩。

## 边界处理

- 碰壁/碰自身/碰障碍物 → Game Over（道具状态例外）
- 穿墙 → 蛇头从对面出现
- 食物刷在蛇身上 → 重新随机
- 快速反向滑动 → 忽略
- 微信切后台 → 自动暂停/恢复
- 道具到期 → 平滑恢复 + 闪烁提示
